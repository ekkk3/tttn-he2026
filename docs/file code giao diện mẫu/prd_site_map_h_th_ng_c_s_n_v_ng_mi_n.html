# TÀI LIỆU ĐẶC TẢ HỆ THỐNG ĐẶC SẢN VÙNG MIỀN (UC1-UC25) ## 1. Site Map Tổng Thể ### A. Phân hệ Khách hàng (Customer) - **Auth:** Đăng ký (UC1), Đăng nhập (UC2) - **Mua sắm:** Trang chủ, Danh mục, Tìm kiếm (UC6), Chi tiết sản phẩm (UC6), Giỏ hàng (UC7) - **Thanh toán:** Checkout/Đặt hàng (UC8), Thanh toán Online/COD (UC9), Kết quả thanh toán (UC25) - **Cá nhân:** Hồ sơ (UC3), Lịch sử đơn hàng (UC4), Theo dõi đơn (UC5), Đánh giá (UC10), Khiếu nại (UC11) ### B. Phân hệ Admin - **Dashboard:** Báo cáo thống kê (UC19) - **Quản trị:** Người dùng (UC14), Nhà cung cấp (UC12), Danh mục (UC16) - **Nghiệp vụ:** Sản phẩm (UC15), Đơn hàng (UC17), Khiếu nại (UC18) ### C. Phân hệ Nhà cung cấp (Supplier) - **Đơn hàng:** Danh sách đơn cung cấp (UC13), Chi tiết đơn (UC13) ### D. Phân hệ Nhân viên kho (Warehouse) - **Nhập hàng:** Yêu cầu nhập hàng (UC20), Quản lý giá nhập (UC24) - **Kho vận:** Quản lý kho/Tồn kho (UC21), Xử lý đơn hàng (UC23), Cập nhật trạng thái (UC22) --- ## 2.
